# Build history

AEGIS was built in 18 phases. These are the per-phase reports written at the time, kept as an
audit trail of what was done and verified when. They describe the project *as it was* at each
phase and are not maintained; the current state is in [`../PROJECT_STATUS.md`](../PROJECT_STATUS.md)
and the roadmap in [`../MASTER_ROADMAP.md`](../MASTER_ROADMAP.md).
