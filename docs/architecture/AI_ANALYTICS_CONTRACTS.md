# AI and Analytics Contracts — Planned (Phases 10, 12, 13, 15)

**Status: PLANNED. No anomaly detection, explainability computation,
retrieval/RAG, or scenario simulation exists yet.** `RiskAssessment` and
`ModelRecord` ship in Phase 1 as storage shapes populated only by
labeled seed examples — see `MODULE_CATALOG.md` module 9 for exactly
what exists versus what's simulated.

## What Phase 1 actually ships

- `RiskAssessment`: subject reference, assessment time, method/model
  version, score + documented scale, confidence/uncertainty field,
  contributing factors, evidence references, explanation text,
  human-review status, reviewer + review timestamp. Seed data creates
  example rows with `method = "seed_example_v0"` so they're
  unmistakably labeled as non-real scoring output, and a real review
  workflow (`POST /api/v1/risk-assessments/{id}/review`) that an
  analyst can actually use against these seeded rows.
- `ModelRecord`: name, version, model type, artifact reference,
  evaluation metadata, status. One placeholder row from seed data,
  referenced by nothing that actually runs inference.

## Binding principles for every future AI/analytics feature (Phases 10, 12, 13, 15)

These are the non-negotiable rules Section 15 lists, restated as
acceptance criteria any later phase's code must satisfy before it ships:

1. Every analytical output identifies its method or model version — no
   score without a named, versioned source.
2. Every conclusion references its supporting evidence where
   applicable — a `RiskAssessment` without evidence references is only
   acceptable when the method genuinely has none to cite (e.g. a
   seeded demonstration), and that must be visible, not hidden.
3. Uncertainty is never hidden — a score without a confidence/
   uncertainty value is incomplete, not "confident by omission."
4. Missing evidence stays missing — a future retrieval/RAG feature
   (Phase 12) must refuse to answer rather than invent a citation when
   its retrieval genuinely found nothing relevant.
5. Synthetic results stay labeled synthetic through every layer —
   database row, API response, and UI — never laundered into
   appearing real by the time a human sees it.
6. A model's output never silently overrides a human review decision —
   `RiskAssessment.human_review_status` exists specifically so a
   human's explicit judgment is the recorded final word, distinct from
   whatever the (currently nonexistent) model produced.
7. AI-generated explanations must not invent citations — this binds
   the future Phase 12 copilot specifically; it has no exception.
8. A score is never described as a calibrated probability unless
   calibration has actually been demonstrated and that demonstration is
   documented (Phase 15's evaluation-metrics work) — until then, scores
   are described as "a score on this documented scale," not "a
   probability."

## What each later phase adds

- **Phase 10 (Explainable AI and Risk Analytics)**: a real anomaly-
  detection method, real uncertainty estimation, real evaluation
  metrics against a real (even if synthetic) labeled dataset, and
  model-version tracking that actually gates which `ModelRecord` a new
  assessment can reference.
- **Phase 12 (Intelligence Copilot and Retrieval)**: document ingestion,
  search, retrieval-augmented generation "where configured" (i.e. only
  when an actual retrieval backend and LLM are wired in — not a
  simulated chat UI), with citations and the explicit refusal behavior
  in principle 4 above.
- **Phase 13 (Simulation and Scenario Analysis)**: synthetic scenario
  generation with configurable assumptions, event playback, and
  comparison of hypothetical outcomes — always labeled as simulation,
  never conflated with real event data.
- **Phase 15 (MLOps and Observability)**: the model registry becomes
  real (versioned artifacts, real evaluation records), with monitoring
  and data-quality metrics over actual production-like traffic.

## What Phase 1 does NOT do

No anomaly detection runs. No explanation is generated by a model —
seed `RiskAssessment.explanation` text is static, written to
demonstrate the field's shape, and says so. No retrieval, no RAG, no
scenario simulation, no model monitoring exists.
